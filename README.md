# PDFKiln for Scoop

`wkhtmltopdf`, `wkhtmltoimage` and `pdfkiln` on Windows: [PDFKiln](https://pdfkiln.org), a drop-in replacement for wkhtmltopdf 0.12.6 rendered by Chromium.

```
scoop bucket add pdfkiln https://github.com/pdfkiln/scoop
scoop install pdfkiln/pdfkiln
```

The manifest installs the Windows archive of a [release](https://github.com/pdfkiln/pdfkiln/releases), its SHA-256 checked. Source, issues and documentation: [pdfkiln/pdfkiln](https://github.com/pdfkiln/pdfkiln). Not affiliated with the wkhtmltopdf project.
